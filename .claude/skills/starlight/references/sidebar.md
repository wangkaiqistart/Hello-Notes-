# Starlight 侧边栏导航参考

> 来源：https://starlight.astro.build/guides/sidebar/

## 概述

侧边栏是 Starlight 文档站点的核心导航。支持自动生成、手动配置、分组嵌套、徽章标记等功能。配置位于 `astro.config.mjs` 的 `starlight.sidebar` 属性中。

---

## 1. 默认侧边栏（无配置时）

不配置 `sidebar` 时，Starlight 根据 `src/content/docs/` 文件系统结构自动生成，使用每个文件的 `title` frontmatter 作为条目名称。

文件结构示例：
```
src/content/docs/
├── constellations/
│   ├── andromeda.md
│   └── orion.md
└── stars/
    └── betelgeuse.md
```

生成的侧边栏：
- constellations
  - Andromeda
  - Orion
- stars
  - Betelgeuse

---

## 2. 内部链接（Internal links）

用 `slug` 属性指向 `src/content/docs/` 中的页面，自动使用页面 `title` 作为标签：

```js
starlight({
  sidebar: [
    { slug: 'constellations/andromeda' },
    { slug: 'constellations/orion' },
  ],
});
```

### 简写形式

直接用字符串代替对象：

```js
starlight({
  sidebar: ['constellations/andromeda', 'constellations/orion'],
});
```

可通过 `label`、`translations`、`attrs` 属性覆盖从页面 frontmatter 推断的值。

---

## 3. 外部链接（Other links）

用 `label` + `link` 指向外部或非文档页面：

```js
starlight({
  sidebar: [
    { label: 'Meteor Store', link: '/shop/' },
    { label: 'NASA', link: 'https://www.nasa.gov/' },
  ],
});
```

---

## 4. 分组（Groups）

用 `label` + `items` 创建带标题的可折叠分组，支持嵌套子分组：

```js
starlight({
  sidebar: [
    {
      label: 'Constellations',
      items: [
        'constellations/carina',
        'constellations/centaurus',
        // 嵌套子分组
        {
          label: 'Seasonal',
          items: [
            'constellations/andromeda',
            'constellations/orion',
            'constellations/ursa-minor',
          ],
        },
      ],
    },
  ],
});
```

---

## 5. 自动生成链接（Autogenerated links）

用 `autogenerate` 指定目录，自动为该目录下所有页面生成链接，子目录变为子分组：

```js
starlight({
  sidebar: [
    {
      label: 'Constellations',
      items: [{ autogenerate: { directory: 'constellations' } }],
    },
  ],
});
```

### 排序规则

- 默认按文件名字母顺序排序
- 可通过页面 frontmatter 的 `sidebar.order` 自定义排序（数字越小越靠前）

---

## 6. 徽章（Badges）

链接和分组都可添加 `badge` 属性：

### 简写形式（使用站点主题色）

```js
{
  slug: 'stars/persei',
  badge: 'Supergiant',
}
```

### 自定义样式

```js
{
  slug: 'stars/sirius',
  badge: { text: 'Stub', variant: 'caution' },
}
```

### 分组徽章

```js
{
  label: 'Moons',
  badge: 'Outdated',
  items: [{ autogenerate: { directory: 'moons' } }],
}
```

### variant 可选值

| 值 | 说明 |
|---|---|
| `note` | 蓝色提示 |
| `tip` | 绿色提示 |
| `caution` | 黄色警告 |
| `danger` | 红色危险 |
| `success` | 绿色成功 |
| `default` | 站点主题色 |

还可通过 `class` 属性指定自定义 CSS 类名。

---

## 7. 自定义 HTML 属性（Custom HTML attributes）

通过 `attrs` 属性添加自定义 HTML 属性到链接元素：

```js
{
  label: 'NASA',
  link: 'https://www.nasa.gov/',
  attrs: { target: '_blank', style: 'font-style: italic' },
}
```

### 为自动生成的链接统一设置属性

```js
{
  autogenerate: {
    directory: 'constellations',
    attrs: { style: 'font-style: italic' },
  },
}
```

页面 frontmatter 中的 `sidebar.attrs` 会与 `autogenerate.attrs` 合并。

---

## 8. 折叠分组（Collapsing groups）

默认分组是展开的。设置 `collapsed: true` 让分组默认折叠：

### 手动分组折叠

```js
{
  label: 'Constellations',
  collapsed: true,
  items: ['constellations/andromeda', 'constellations/orion'],
}
```

### 自动生成子分组折叠

```js
{
  label: 'Constellations',
  items: [
    {
      autogenerate: {
        directory: 'constellations',
        collapsed: true,
      },
    },
  ],
}
```

---

## 9. 通过 frontmatter 自定义自动生成链接

在页面的 YAML frontmatter 中设置 `sidebar` 字段：

```yaml
---
title: My page
sidebar:
  label: Custom sidebar label  # 自定义显示标签
  order: 2                     # 排序权重，数字越小越靠前
  hidden: true                 # 从侧边栏隐藏此页面
  badge:
    text: New
    variant: tip
  attrs:
    target: _blank             # 自定义 HTML 属性
---
```

### SidebarConfig 类型定义

```typescript
interface SidebarConfig {
  label?: string;        // 自定义标签，默认使用页面 title
  order?: number;        // 排序权重
  hidden?: boolean;      // 是否隐藏（默认 false）
  badge?: string | BadgeConfig;  // 徽章
  attrs?: Record<string, string | number | boolean | undefined>;  // HTML 属性
}
```

注意：`sidebar` frontmatter 仅对自动生成链接和用 `slug` 定义的链接有效，对用 `link` 定义的链接无效。

---

## 10. SidebarItem 完整类型

```typescript
type SidebarItem =
  | string  // 内部链接简写
  | ({
      translations?: Record<string, string>;
      badge?: string | BadgeConfig;
    } & (
      | {
          // 外部链接
          link: string;
          label: string;
          attrs?: Record<string, string | number | boolean | undefined>;
        }
      | {
          // 内部链接
          slug: string;
          label?: string;
          attrs?: Record<string, string | number | boolean | undefined>;
        }
      | {
          // 链接分组
          label: string;
          items: SidebarItem[];
          collapsed?: boolean;
        }
    ))
  | {
      // 自动生成
      autogenerate: {
        directory: string;
        collapsed?: boolean;
        attrs?: Record<string, string | number | boolean | undefined>;
      };
    };
```

## 11. 完整配置示例

```js
// astro.config.mjs
import { defineConfig } from 'astro/config';
import starlight from '@astrojs/starlight';

export default defineConfig({
  integrations: [
    starlight({
      title: 'My Docs',
      sidebar: [
        // 单个链接
        { label: 'Home', link: '/' },

        // 手动分组
        {
          label: 'Start Here',
          items: [
            { slug: 'intro' },
            { slug: 'installation' },
            'tutorial',          // 简写
            'next-steps',        // 简写
          ],
        },

        // 自动生成分组（默认折叠子分组）
        {
          label: 'Reference',
          items: [
            {
              autogenerate: {
                directory: 'reference',
                collapsed: true,
              },
            },
          ],
        },

        // 带徽章的折叠分组
        {
          label: 'Advanced',
          collapsed: true,
          badge: { text: 'WIP', variant: 'caution' },
          items: [
            { slug: 'advanced/api', badge: 'New' },
            { slug: 'advanced/plugins' },
          ],
        },

        // 外部链接（新标签页打开）
        {
          label: 'Resources',
          items: [
            {
              label: 'GitHub',
              link: 'https://github.com/example',
              attrs: { target: '_blank' },
            },
          ],
        },
      ],
    }),
  ],
});
```

## 速查表

| 功能 | 关键属性 | 说明 |
|------|---------|------|
| 内部链接 | `slug` 或字符串 | 指向 `src/content/docs/` 下的页面 |
| 外部链接 | `label` + `link` | 任意 URL |
| 分组 | `label` + `items` | 可嵌套，支持折叠 |
| 自动生成 | `autogenerate.directory` | 按目录自动创建链接和子分组 |
| 徽章 | `badge` | 字符串或 `{text, variant, class}` |
| 折叠 | `collapsed: true` | 分组默认收起 |
| 排序 | frontmatter `sidebar.order` | 数字越小越靠前 |
| 隐藏 | frontmatter `sidebar.hidden` | 从侧边栏隐藏 |
| 自定义属性 | `attrs` | 添加 HTML 属性（如 target、style） |
| 自定义标签 | `label` 或 frontmatter `sidebar.label` | 覆盖默认页面标题 |
