学面通 AI 的产品原型设计，核心不是先画页面，而是先拆清楚：用户要完成什么任务、系统要提供哪些能力、前端页面应该围绕哪些模块组织。

<Aside type="tip" title="核心目标" icon="rocket">
  先拆透需求逻辑，再明确功能模块，最后搭建前端页面骨架，为后续开发打好基础。
</Aside>

## 产品定位

学面通 AI 是面向职场人的全链路 AI 赋能助手，覆盖“学 → 练 → 测 → 面 → 复盘 → 沉淀”的成长过程。

<CardGrid>
  <Card title="学习" icon="open-book">
    快速问答、知识精讲、难点拆解，帮助用户高效理解学习内容。
  </Card>
  <Card title="训练" icon="approve-check">
    个性化题库、评分、薄弱点定位，让训练更有针对性。
  </Card>
  <Card title="求职" icon="puzzle">
    简历优化、模拟面试、面试复盘，提升求职准备质量。
  </Card>
  <Card title="沉淀" icon="setting">
    把学习记录、复盘结果和核心笔记沉淀成个人知识资产。
  </Card>
</CardGrid>

## 正向成长循环

学面通 AI 的核心逻辑，是让各个模块形成一个闭环，而不是孤立功能堆叠。

<Steps>

1. **学**：通过答疑、精讲和结构化内容建立理解。

2. **练**：根据知识点和薄弱点进行针对性训练。

3. **测**：通过题库、评分和模拟场景检验掌握程度。

4. **面**：进入简历优化、模拟面试和求职表达训练。

5. **复盘**：根据表现分析问题，抽取新的薄弱点。

6. **沉淀**：把知识点、训练结果和复盘结论保存为长期资产。

</Steps>

<Aside type="note" title="循环价值">
  薄弱点触发学习和训练，面试结果自动进入复盘，复盘内容继续沉淀，形成持续成长的飞轮。
</Aside>

## 用户操作路径

产品原型不能只停留在“有哪些功能”，还要继续拆到“用户怎么走”。流程图的价值，就是把每个模块的入口、分支、输出和回流关系梳理清楚。

<Aside type="tip" title="设计重点">
  用户路径要回答三个问题：用户从哪里进入、AI 在中间做什么、结果最终沉淀到哪里。
</Aside>

<Tabs>
  <TabItem label="学习模块" icon="open-book">
    学习模块的主入口是用户提问。系统需要先判断用户是否选择了具体模式，再决定是快速回答、知识精讲，还是进入题库训练。

    <Steps>

    1. 用户输入问题并发送。

    2. 如果没有选择模式，默认进入快速回答，直接生成答案。

    3. 如果选择知识精讲，AI 输出结构化知识卡片，并配合一对一语音讲解。

    4. 如果选择刷题评测，用户输入岗位、技术栈、题目需求或上传简历。

    5. AI 二次确认题型、题目难度和题量，用户确认后生成题库。

    6. 用户答题后，AI 对答案评分，抽取薄弱点，并把薄弱点回流到知识精讲。

    7. 有价值的答案、讲解和薄弱点可以一键存入笔记模块。

    </Steps>

  </TabItem>

  <TabItem label="面试模块" icon="approve-check">
    面试模块围绕求职准备展开，核心分成简历优化、模拟面试、面试复盘和知识精讲四条路径。

    <Steps>

    1. 用户输入问题后，先选择面试相关模式。

    2. 简历优化：用户上传简历或输入简历资料，AI 对简历进行深度分析，指出优缺点，并生成可下载的优化版简历。

    3. 模拟面试：AI 提取用户简历信息，调用语音识别和语音合成，模拟一对一面试，结束后进入复盘。

    4. 面试复盘：用户上传真实面试音频，AI 分析表现，生成复盘结果和改进建议。

    5. 知识精讲：针对面试暴露出的薄弱点，AI 输出结构化知识卡片和语音讲解。

    </Steps>

  </TabItem>

  <TabItem label="笔记模块" icon="star">
    笔记模块不是单独的孤立功能，而是承接学习、训练、面试和复盘结果的沉淀入口。

    - 学习模块中有价值的答案、知识卡片、题目解析，可以一键加入笔记。
    - 面试模块中生成的简历建议、面试复盘、薄弱点分析，也可以保存到笔记。
    - 笔记支持后续编辑和整理，让一次性的 AI 输出变成长期可复用的个人知识资产。

  </TabItem>
</Tabs>

| 模块     | 关键入口                 | AI 处理                                | 主要输出                               | 回流位置           |
| -------- | ------------------------ | -------------------------------------- | -------------------------------------- | ------------------ |
| 学习模块 | 用户提问、选择模式       | 快速回答、知识精讲、题库生成、答案评分 | 答案、知识卡片、题库、薄弱点           | 知识精讲、笔记模块 |
| 面试模块 | 简历、面试模式、面试音频 | 简历分析、模拟面试、复盘分析、知识讲解 | 优化简历、面试记录、复盘报告、改进建议 | 知识精讲、笔记模块 |
| 笔记模块 | 各模块一键保存           | 存储、编辑、整理                       | 个人笔记、复盘材料、知识资产           | 长期学习与复习     |

## 前端页面骨架

前端页面骨架要围绕产品模块组织，让用户能从学习、训练、面试、复盘和沉淀之间自然流转。

| 页面模块      | 核心内容                               | 设计重点                     |
| ------------- | -------------------------------------- | ---------------------------- |
| 首页 / 工作台 | 学习进度、待训练任务、薄弱点、最近复盘 | 快速看到当前状态和下一步行动 |
| 学习答疑页    | 问答输入、知识精讲、结构化卡片         | 支持快速提问和深度理解       |
| 训练题库页    | 个性化题目、评分、错题、薄弱点         | 让练习结果能反向驱动学习     |
| 简历优化页    | 简历上传、图像 / 文本分析、优化建议    | 把简历问题转化为可训练项     |
| 模拟面试页    | 语音面试、实时转写、答题记录           | 强化真实面试场景体验         |
| 面试复盘页    | 表现分析、复盘报告、改进建议           | 明确下一轮训练方向           |
| 笔记沉淀页    | 学习笔记、复盘内容、富文本编辑         | 把过程结果变成长期知识资产   |

## 前端实现关注点

<CardGrid>
  <Card title="页面与模块分离" icon="puzzle">
    页面负责组织流程，组件负责复用展示，避免把所有逻辑写进单个页面。
  </Card>
  <Card title="状态与数据清晰" icon="setting">
    学习进度、训练结果、面试记录和笔记内容要有清晰的数据流。
  </Card>
  <Card title="Mock 数据先行" icon="terminal">
    前端骨架阶段可以先用 Mock 数据渲染页面，后续再接真实接口。
  </Card>
  <Card title="组件可复用" icon="random">
    卡片、列表、评分、报告、输入区等通用结构要尽量抽成组件。
  </Card>
</CardGrid>

## 总结速记

<Aside type="tip" title="速记" icon="star">
  学面通 AI 的产品原型可以按一句话记：围绕“学、练、测、面、复盘、沉淀”搭建模块，让学习、训练、求职和知识资产形成正向循环。

用户路径要按“入口 → 模式分支 → AI 处理 → 结果输出 → 笔记沉淀”来设计。前端骨架的重点不是页面多，而是模块边界清楚、流程能闭环、数据能流转。

</Aside>
