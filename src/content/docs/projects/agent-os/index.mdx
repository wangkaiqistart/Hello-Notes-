这是一个持续开发的 Agent OS 实战项目。项目使用 AI Coding 和 Harness 方法，逐步实现一个包含 ReAct、Memory、Tool、Provider、Sandbox、API 和企业治理能力的 Agent 运行底座。

<Aside type="tip" title="项目定位" icon="rocket">
  这里沉淀的是一个持续演进的工程项目，不是一次性的概念笔记。设计、实现、测试和部署文档会随着代码实践同步更新。
</Aside>

## 项目目标

- 用一个清晰的 ReAct Loop 跑通 Agent 的推理、工具执行和结果回填。
- 通过 Provider 抽象支持模型切换，避免业务逻辑绑定单一模型厂商。
- 建立 Session、长期记忆和任务记忆的持久化能力。
- 提供 Skill、MCP 和原生 Tool 三档扩展方式。
- 在 Sandbox、权限、审计和凭证保护的基础上接入企业系统。
- 使用 Harness、Spec-Kit 和自动检查，把 AI Coding 纳入可复用的研发流程。

## AI Coding 开发约定

后续实现遵循以下原则：

1. 先写清目标、边界、验收标准和关键技术取舍，再让 AI 参与实现。
2. 按可运行、可验证的小任务拆分，避免一次性生成整个系统。
3. AI 生成的设计和代码必须经过人工理解、测试、构建和 Review。
4. 每次实现都同步沉淀规则、Skill、测试方法和问题复盘，形成可复用资产。
5. 涉及工具调用、文件、网络、凭证和生产数据时，默认采用最小权限和可审计设计。
