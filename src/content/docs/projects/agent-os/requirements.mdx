> **范围重点**：第一阶段只做能跑通、能扩展、能验证的 Agent 底座，不把所有治理和集成能力一次性塞进核心版本。

## 功能范围

1. 连接一个或多个 LLM Provider。
2. 运行带工具调用的 ReAct Loop。
3. 管理 Session、短期上下文和长期记忆。
4. 注册内置 Tool、Skill/MCP Tool 和 Java Plugin Tool。
5. 通过 CLI、Channel 和 Web Service 接入。
6. 提供 Profile、配置和密钥加载能力。
7. 记录工具调用、状态和必要的审计信息。

## 运行模式

| 模式      | 用途                      |
| --------- | ------------------------- |
| `chat`    | 本地终端交互和调试        |
| `serve`   | 通过 HTTP 提供 Agent 能力 |
| `gateway` | 同时连接多个消息通道      |

三种模式共享核心引擎、Profile 和 Session 存储，区别只在消息入口。

## 不做什么

- 不在核心阶段实现所有业务领域 Agent。
- 不把编排平台、知识库和模型训练平台混进运行时。
- 不默认启用高风险 Shell、文件和网络权限。
- 不用自动记忆提炼替代明确的写入策略。

## 非功能要求

- Provider、Tool、Memory 和 Channel 通过接口隔离实现。
- 配置与密钥不写入代码和日志。
- 工具调用有参数校验、超时、权限和审计。
- ReAct 有最大轮数、错误处理和可解释状态。
- 关键模块可测试、可替换、可独立演进。
