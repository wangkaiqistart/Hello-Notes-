## 阶段判断

资料将 2026 年描述为 AI 基础设施快速成形的阶段：模型调用、工具连接、MCP、Subagent、SDD 和 Agent 运行时逐渐收敛为共同的工程抽象。

## 比宣传数字更重要的信号

- AI 编程的核心差异从“会不会调用工具”转向“能不能持续稳定地使用工具”。
- 自主编程仍然依赖清晰范围、参考实现和外部验证，不能把 Demo 直接当作生产能力。
- 企业采用的关键不是单次生成速度，而是权限、审计、测试、回滚和责任链是否完整。
- No-code、Coding Agent 和传统 IDE 并非简单替代关系，它们处在不同的任务和控制层。

## 使用这类资料时的核验顺序

1. 回到项目官方仓库和文档确认当前版本。
2. 区分作者观察、公开数据和个人推断。
3. 给数字补充时间、样本和统计口径。
4. 不用单个成功案例推导普遍生产结论。
