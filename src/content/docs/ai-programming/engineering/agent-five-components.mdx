## 五个组件

1. **LLM**：根据当前状态进行理解和决策。
2. **Tools**：对文件、接口、浏览器或业务系统执行动作。
3. **Memory**：承载当前任务状态和跨会话经验。
4. **Loop**：把观察、思考、行动和反馈连接起来。
5. **Environment**：Agent 实际感知和改变的外部世界。

只有模型或一次工具调用，不足以说明系统就是 Agent。判断重点是：它能否基于环境反馈自主决定下一步，并在循环中持续推进目标。

## 和相邻概念的区别

| 概念     | 核心特征                                                        |
| -------- | --------------------------------------------------------------- |
| LLM      | 负责生成和推理，不天然执行外部动作                              |
| Chatbot  | 主要围绕对话响应，不一定改变外部状态                            |
| Workflow | 步骤通常由人预先固定                                            |
| Agent    | 根据状态和反馈动态选择下一步                                    |
| Agent OS | 在 Agent Runtime 之上管理多个 Agent、渠道、工具、记忆和治理能力 |

这个模型也适合分析 OryxOS、Hermes、Claude Code 等系统：先拆组件，再判断它们的自动化、状态和治理边界。
