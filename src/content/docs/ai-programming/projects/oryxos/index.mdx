OryxOS 是一套面向企业场景的 Java 原生 Agent OS 设想。它把模型、工具、渠道、记忆和运行时放进企业自己的基础设施，重点解决可控、可审计和可扩展的问题。

本项目资料按四种产物阅读：

- [业界调研](./research/)：确认 Agent OS 的定义、市场空白和项目边界。
- [需求文档](./requirements/)：定义五大核心能力和非功能约束。
- [技术方案](./technical-design/)：说明运行时内核、ReAct、Memory、Tool 和 Web Service 的实现方向。
- [AI 编程指南](./ai-development-guide/)：把需求和技术方案转成 Spec-Kit 加手工提示词的实施流程。

这里的价值不只是 OryxOS 本身，也可以作为“如何把领域调研转成可执行 AI 编程项目”的案例。
