## 核心能力

1. **Provider**：统一接入不同 LLM。
2. **ReAct Loop**：让 Agent 根据工具结果持续推进任务。
3. **三层 Memory**：区分任务状态、长期记忆和用户信息。
4. **Tool / Plugin**：同时支持内置工具、MCP 和自定义扩展。
5. **Web Service**：通过接口对外暴露 Agent 能力。

配套能力包括工作区初始化、Profile 配置、Channel 接入、Session 管理、命令行运行和密钥加载。

## 需求边界

核心阶段先做运行时内核，不把多租户、完整审计、复杂治理和大规模分布式能力混入第一版。每项扩展都应有清晰的进入条件和验收标准。
