When 是一个独立部署的分布式延时投递组件：业务方通过 HTTP API 提交消息，系统在指定时间把消息投递到 HTTP、Kafka 或其他下游。

本项目资料按四种产物阅读：

- [业界调研](./research/)：区分消息中间件、SDK、任务队列和独立延时服务。
- [需求文档](./requirements/)：定义训练营 MVP 的功能范围和验收边界。
- [技术方案](./technical-design/)：说明集群、时间轮、副本和故障切换设计。
- [AI 编程实施指引](./ai-development-guide/)：说明如何用 Harness、任务卡和 Review 推进开发。
