OpenWiki 是 Deep Agents 生态里的一个具体知识生产工具，不是上下文管理 API 本身。我会复用已有的 OpenWiki 总览笔记，这里只记录它如何为 Agent 提供持久化仓库上下文、Claims 和入口指引。

## 后续整理重点

- OpenWiki 生成的 Markdown、Claims 和入口文件。
- Wiki 内容如何被 Agent 的文件系统和 Memory 读取。
- Code mode 与 Personal mode 的边界。
