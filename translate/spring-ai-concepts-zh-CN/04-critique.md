# AI 核心概念初稿审校

## 准确性

- 初稿把 Embedding 明确为数值表示，由嵌入模型执行向量化，符合源文“numerical representations”，接受。
- Prompt Engineering 及高维语义空间是源文存在、旧稿省略的说明，初稿恢复后仍保持简明，接受。
- SQL 对比改为表达任务的方式差异，避免旧稿超出源文的确定性推论，接受。
- 结构化输出限定为图示的提示词驱动转换方式，并恢复可能多次交互的限定，符合源文；不扩展为所有原生结构化输出的实现说明。
- 源文将 Prompt Stuffing 与 RAG 近似混称。初稿明确“补充参考资料”与“先检索再补充”的关系，是必要的概念澄清。旧稿已经提到检索，不能声称它完全混淆二者。
- 工具调用第二步恢复“模型决定调用时”的条件，接受；开头仍说“将方法提供给模型”，容易让初学者忽略传递的是工具定义，需明确业务方法注册及请求中提供定义。
- 模型辅助评估不要求额外引入不同的评估模型；初稿改写准确，接受。

## 中文表达

- “用模型数据渲染视图”在 AI 语境下容易混淆，明确由 Map 中的变量渲染提示词即可。
- “说明模型应如何行动”可以收紧为“设定模型行为与交互背景”。
- 保留向量距离和相似度，不把它们混为同一种度量，也不承诺相似检索必然正确。

## 注释与取舍

- 源文关于 GPT、Claude 等旧型号的容量数字、2021 年知识截止时间、650GB 语料大小保留在英文来源快照中，不作为当前规格放回正文；这是延续旧稿的处理，不是本轮新纠错。
- 原文提示技巧论文链接与具体“深呼吸”引述的对应关系未在本轮独立验证，继续省略，不宣称该结论错误或适用于所有模型。

- “仍需解析和字段校验”为已有工程说明，保留但不包装为原文逐字内容。
