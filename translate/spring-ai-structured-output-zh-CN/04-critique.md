# 审校记录

## 准确性

- 逐段对照来源，初稿保留 6 个主要章节、3 个子节、8 个 Java 示例、8 行速查表和唯一流程图。
- 默认方式与原生方式的适用范围已经区分：提示词驱动方式不要求提供方支持原生 Schema API，原生方式必须查询模型支持范围。
- 默认最多尝试 3 次已按 attempts 翻译，未写成额外重试 3 次。需要补明次数有限、达到上限仍可能失败，避免原文标题“Don’t Fail”造成绝对保证的误读。
- .entity 的 call-only 限制已保留，未推广为流式文本不能聚合后另行解析。
- ResponseEntity 结果容器需明确为 Spring AI 类型，补充完整包名以区分 HTTP ResponseEntity。
- Schema 约束和业务内容正确性不应混为一谈，在组合使用之后补一条简短说明。
- 自定义转换器部分避免断言内置 JSON 转换器完全不能处理 Markdown 围栏，保持“特殊处理需求”的条件。
- 工具调用说明限定为该转换器不参与工具协议的结构化机制，不扩展为自动校验工具的业务结果。
