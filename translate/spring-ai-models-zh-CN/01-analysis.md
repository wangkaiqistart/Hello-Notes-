## 授权范围

用户要求模型内容精简成小章节，非必要内容保留官网查询。只保留统一模型接口的作用、聊天 / Embedding / 图像 / 转写 / 语音 / 审核类型、学习顺序和官网查询入口。省略框架其他 API 概览与 UML、所有提供方安装配置、参数大全。该页是精选导读，不冒充原文完整翻译。
